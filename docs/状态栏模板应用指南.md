# 状态栏模板系统应用指南

本系统通过对 6 张成熟参考卡（遗界：零号边境、御兽、斗破苍穹沙盒大世界、埃瑟尔德大陆、二十一人会、北风之殇）的逆向分析，提炼出一套可复用、可配置、可自适应的状态栏模板方案，已集成进 MVU 系统架构。

## 一、系统架构

状态栏由三个解耦的层组合而成，每层可独立替换：

**注入层** — 状态栏如何进入聊天消息。当前沿用占位符替换：AI 在回复中输出 `<StatusPlaceHolderImpl/>`，导出时由 regex_scripts 把它替换为状态栏 HTML（`markdownOnly` 仅前端显示，另有 `promptOnly` 脚本把占位符从 AI 上下文移除）。参考卡还存在整条消息包裹、结构化数据捕获、追加到末尾三种注入模式，本系统预留了扩展空间，但默认使用最稳定的占位符方案。

**数据层** — 状态栏如何读取变量。采用 JS 运行时动态渲染：状态栏脚本通过 MVU 运行时（MagVarUpdate bundle，导出时已内嵌）提供的 `getAllVariables()` 读取 `stat_data`，并订阅 `Mvu.events.VARIABLE_UPDATE_ENDED` 事件，实现「AI 更新变量 → 状态栏自动重渲染」。脚本对运行时全局做了守卫，运行时未就绪时用初始值兜底，因此预览与导出都稳定。

**渲染层** — 状态栏长什么样。schema 反射根据变量类型自动选择原子组件，CSS 变量驱动主题，一套组件可换多套皮肤。

## 二、模板选择标准

系统内置两类模板，外加「无状态栏」与「AI/手动自定义」：

**紧凑HUD** — 信息密度高的窄条面板，适合变量较少（1~6 个）、追求沉浸感、希望状态栏常驻且不抢戏的卡片。默认主题为战术终端。典型场景：生存、战术、单角色情感追踪（如分阶段模式的情感天平）。

**角色面板** — 带头像徽章、可折叠分区的完整面板，适合变量丰富、分多个维度（系统/健康/装备/背包等）的角色卡。默认主题为羊皮纸。典型场景：RPG、沙盒大世界、多属性养成。

**无状态栏** — 不生成状态栏（默认值）。适合纯叙事、不需要可视化状态的卡片。

**AI/手动自定义** — 直接编辑完整 HTML 文档，适合有特定视觉需求、内置模板无法满足的高级用户。

选择决策树：变量少且要沉浸 → 紧凑HUD；变量多且分维度 → 角色面板；不要状态栏 → 无；要完全自定义 → AI/手动。

## 三、主题选择

四套主题对应四种美学范式，均取自参考卡：

**战术终端**（北风之殇范式）— 暗黑等宽终端风，枯金标题、绿黄红三态、CRT 内凹感。适合生存、科幻、战术、末日题材。

**羊皮纸**（遗界/埃瑟尔德范式）— 暖色衬线古风，金属浮雕头像、双层边框。适合玄幻、武侠、西幻、古典题材。

**毛玻璃光幕**（斗破苍穹范式）— 半透明金边、背景模糊、外发光。适合仙侠、魔幻、华丽风格题材。

**素雅宣纸**（御兽范式）— 浅色楷体、暗红点缀、柔和留白。适合日常、养成、清新风格题材。

主题与模板正交：任意模板可搭配任意主题。主题仅覆盖 CSS 变量，组件结构不变。

## 四、配置方法

在向导「分阶段模式」步骤的「状态栏模板」区块配置：

1. 选模板类型（紧凑HUD / 角色面板 / 无 / AI手动）。
2. 选主题风格（四选一，仅内置模板需要）。
3. 填状态栏标题（显示在头部，默认取标题首字作头像）。
4. 切换「显示头像徽章」「默认折叠分区」两个开关。
5. 实时预览框即时显示效果（初始值状态）。

配置存于 `mvu.statusBarStyle`（模板 id）、`mvu.statusBarOptions`（themeId/title/showAvatar/collapseAll）、`mvu.statusBarHtml`（生成的 HTML）。切换分阶段剧情模板时，状态栏配置会保留并按新变量自动重生成。

## 五、Schema 反射与自适应机制

系统读取 MVU schema，按变量类型自动选择组件，无需手动指定：

- `z.coerce.number()` 且范围跨度 ≤ 1000 → **资源条**（渐变填充 + 数值 + 三态变色：单向条 ≤30% 转红、≤60% 转黄）。
- `z.coerce.number()` 大范围（如金币 0~99999）→ **数值行**。
- `z.enum([...])` → **语义徽章**。
- `z.boolean()` → **状态标签**（是/否，是转红）。
- `z.string()` → **标签/值数据行**。
- `z.object()/z.record()/z.array()` → **列表**（自动遍历条目，识别 `数量` 字段）。
- `$` 前缀的隐藏变量 → **不显示**。

自适应规则：

- **变量数量自适应**：按 schema 分区自动分组；角色面板多分区时首个展开、其余折叠，避免信息过载。
- **变量类型自适应**：上述反射规则保证任意 schema 都能合理呈现。
- **布局自适应**：`@media (max-width:520px)` 移动端降内边距、缩头像。
- **主题自适应**：组件只引用 `var(--sb-*)`，换主题即换肤。

## 六、AI/手动自定义指南

自定义状态栏须输出完整 HTML 文档（包在 ```html 代码块中），含 `<style>` + `<script type="module">` + `<body>`。脚本可用以下运行时全局（由内嵌 MVU bundle 提供）：

- `getAllVariables()` — 返回全部变量对象，根为 `stat_data`。
- `_.get(obj, 'stat_data.路径', 默认值)` — 安全取值（lodash 全局）。
- `waitGlobalInitialized('Mvu')` — 等待运行时就绪。
- `eventOn(Mvu.events.VARIABLE_UPDATE_ENDED, fn)` — 订阅变量更新事件。
- `$`（jQuery）、`errorCatched(fn)`（错误包裹）。

推荐结构：`async function init(){ await waitGlobalInitialized('Mvu'); populate(); eventOn(Mvu.events.VARIABLE_UPDATE_ENDED, populate); } $(errorCatched(init));`。也可用 `{{format_message_variable::stat_data.路径}}` 宏做纯静态渲染（无需脚本，每楼层快照独立）。

导出时，含 `<script>` 或 ```html 开头的状态栏会被识别为运行时报文，原样注入（不去换行、不转宏）；普通片段则走旧的宏转换路径，二者兼容。

## 七、导出与运行时集成

导出时 card-exporter 自动：把状态栏 HTML 作为 `<StatusPlaceHolderImpl/>` 的替换内容写入 regex_scripts；内嵌 MagVarUpdate bundle 与 Zod schema 脚本（提供运行时全局与变量校验）；first_mes 写入变量初始化。导入 SillyTavern 后，AI 回复触发变量更新，状态栏随事件实时刷新。

## 八、扩展方向

新增模板：在 `status-bar-templates.ts` 的 `STATUS_BAR_TEMPLATES` 注册一个实现 `generate(sections, opts)` 的对象即可。新增主题：在 `STATUS_BAR_THEMES` 添加 CSS 变量覆盖包。新增注入模式：在 card-exporter 扩展 regex_scripts 生成逻辑（如整条包裹、结构化捕获）。
