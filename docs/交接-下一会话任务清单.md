## 工作方法约定（保持同一质量标准）

1. **每个逻辑提交独立可编译**：提交后逐个 checkout 跑 `npx tsc --noEmit` 验证。本批就靠它抓到一个提交划分错误（prop 的传入与声明分在了两个提交）。用后台任务跑，别在前台等（每个提交约 1.5 分钟）。
2. **每批改动落盘前跑对抗式复查**：用 Workflow 起 3-4 个视角的审查 agent，每条发现再起独立 agent 试图驳倒，只修被确认的。本批三轮分别确认 13/5/15 条（驳回 1/1/8）。这一步不能省——高危项全部来自它。
   - 复查 agent 会在仓库里留探针测试文件（`__probe_*.test.ts` 等），**复查结束后记得删**，否则会污染后续的 checkout sweep。
3. **并行 agent 严禁改 `src/i18n/translations.ts`**（并发读改写会互相丢编辑）：让它们报「键名+中文文案」清单，由主会话统一添加。注意：缺键时 `t()` 返回**空串**（不是键名）。
